# 预登记：小样本热门估计 (Small-Sample Popularity Estimate)

写于 2026-10-14，**在通宵实验运行之前**。英文版：[`01_preregistration_en.md`](01_preregistration_en.md)。
原始结果在 `results/small_sample_popularity/`；结果解读在 `02_results_zh.md`。

## 1. 你想验证的是什么 / 白话

从一个大群体里只抽一小批人，每人只留几条过去的选择，只用这些数据排出一份推荐清单。
**这份清单有多准？** 以及：**什么时候用同一批小样本训练的个性化推荐，才比直接推热门榜更值？**

热门榜在这里被当作统计量（像均值、方差），只不过被估计的东西不是一个数字，而是一份排序。

## 2. 两种"真相"（两种都报告，并排放）

| 名称 | 是什么 | 回答什么问题 |
| --- | --- | --- |
| **真相 A** | 同一个时间窗口里，群体中**所有人**的物品计数 | 估计问题：小样本的清单离全群体的清单有多远？ |
| **真相 B** | 群体在截止时间**之后**真正做出的选择 | 预测问题：这份清单对人们接下来的选择有多大用？ |

下面会用到的词：

- **N** = 抽了多少人；**k** = 每人保留多少条过去的选择（"all" = 保留全部）。
- **一次抽样（draw）** = 一个随机样本。每个格子都重复很多次，这样才能量出随机波动。
- **验证小组（panel）** = 最多 1,500 位**不在任何样本里**的人。给他们看自己的 k 条过去选择，再用他们真实的后续选择给清单打分。
- **旧榜（stale list）** = 更早时间段里群体的物品计数（"去年的榜"）。

现在就定死的规则：

- 一条**选择** = 评分不低于 4（显式评分数据），或任意一次互动（隐式数据）。同一个人对同一个物品只算第一次。
- 截止时间 T0 = 所有选择时间的第 80 百分位。更早的是**收集期**，更晚的是**未来**。旧榜 = 第 55 百分位之前的选择。
- 只有早期选择不少于 20 条（Amazon 数据 10 条，lastfm-1k 5 条）的人才算群体成员。其中 80% 是被抽样的**群体**，20% 留给验证小组。
- N 不超过群体的 40%，这样"有限总体"的影响很小。

## 4. 抽什么、估什么

| 网格 | 取值 |
| --- | --- |
| N（人数） | 20, 40, 100, 200, 400, 1000, 2000, 4000, 10000, 20000（不超过群体的 40%） |
| k（每人几条） | 1, 2, 5, 10, 20, all（不超过该数据集允许的最小值） |
| 每格重复次数 | 热门榜 60 次；训练模型 20 次；排名区间 30 次；子群体 40 次；隐私 20 次 |

估计方法：

| 名称 | 做什么 |
| --- | --- |
| `count` | 按被抽到的人选了多少次来排（最朴素的热门榜） |
| `shrunk` | 把样本计数和旧榜混合；混合强度由样本自己估出来 |
| `lcb` | 按每个物品选择率的保守下界来排 |
| `ht` | 对有偏抽样做反向加权（只用于有偏抽样的实验） |
| `knn`、`ease` | 只用样本训练的个性化模型（物品近邻；EASE） |
| `hybrid`（混合） | `(1-w)·热门 + w·个性化`；w 和模型**只用样本内部**来选：把每个被抽中的人的一部分选择藏起来再预测。藏法有两种：*随机藏*、*把最新的先藏起来（按时间）* |

指标：前 10 / 前 100 与真相的重合度；rank-biased overlap（0.9 和 0.98）；真实前 100 上的 Kendall tau；在真相计数下的清单 NDCG@100（软指标，不要求顺序完全对）；以及验证小组上、用他们真实后续选择算的 NDCG@100 和 recall@100。

## 5. 运行前我已经知道的（完整披露）

- 试跑，只在 ml-1m 上约 20 次抽样：代码能跑；全量样本能精确还原真相 A；几个格子的现象是：
  旧榜比所有小样本都好；k=10 时个性化输给热门榜，k=20、N=1000 时反超；用"随机藏"选权重的混合，比"按时间藏"的更相信个性化。
  **这些试跑结果不用于任何结论**；正式实验换了随机种子，并覆盖全部 11 个数据集。
- 理论预检（没有抽样）：在所有数据集上，即使 N = 5,000，榜首能被**正确排序**的物品也只有 1 到 2 个（Dyer-Owen 上界）。要找出精确的前 10 名，大约需要 10^4 到 10^7 个人。所以下面的结论用软指标（NDCG、捕获的总量），精确重合度只作描述。
- 真相 A 与真相 B 之间的差距在参考清单上很大（例如 ml-1m 的验证小组：用"完美的后续榜"得 0.246，用全群体早期榜只有 0.184）。

## 6. 确认性假设（3 个）

下面的判定规则现在就定死。每个假设先按数据集判定，再跨数据集用"为正的数据集个数"和合并区间判定。区间是对抽样次数做的 95% bootstrap。看到结果后不再调整。

### C1. 广度胜过深度（估计清单时）

*白话：* 保留的总选择数相同时，"很多人、每人几条"比"少数人、每人很多条"给出更好的热门榜。

- **量：** 真相 A 下 `count` 的 NDCG@100。对每个数据集，以及网格中出现两次以上的每个总预算 B = N·k（B = 200、400、1000、2000、4000、10000…），差值 =（最宽的格子：N 最大、k 最小）−（最深的格子：N 最小、k 最大）。
- **预测：** 至少 75% 的（数据集，预算）对为正，且合并区间不含 0。
- **证伪：** 为正的对不超过 50%，或合并区间整体在 0 以下。
- **为什么这么预期：** 同一个人的选择彼此相似，再多一条同一个人的选择，提供的新信息少于多一个新的人（"设计效应"）。

### C2. 用诚实权重的混合，从不差于较好的单一清单，有时比两者都好

*白话：* 把热门和个性化混合，只用样本来选混合比例，到处都不比两者中较好的那个差，并且在相当比例的格子里比两者都好。

- **量：** 训练模型那一阶段的验证小组 NDCG@100（7 个数据集，N 从 100 到 4,000，k = 5、10、20、all）。`hybrid_time`（把每个被抽中者最新的选择藏起来来选权重）对比 `热门` 与 `personalized_time`（同样方法选出的最佳纯个性化模型）中较好者。
- **预测：** (a) 至少 90% 的格子里，混合比较好的单一清单最多低 0.002；(b) 至少 20% 的格子里，混合高于两者，且按抽样配对的区间不含 0；(c) 至少 70% 的格子里，`hybrid_random`（随机藏）给个性化的权重不低于 `hybrid_time`。
- **证伪：** (a) 在超过 25% 的格子不成立，或 (b) 成立的格子不到 10%。

### C3. 存在一个交叉样本量，并随 k 增大而变小

*白话：* 人数够多时，用样本训练的模型在真实后续选择上会胜过热门榜；每人给的选择越多，需要的人越少。

- **量：** N*(k) = 网格中使 `personalized_time` 在验证小组上胜过 `热门`（95% 区间在 0 以上）的最小 N。
- **预测：** k = 20 与 k = all 时，7 个数据集中至少 5 个存在 N*(k)（≤ 4,000）；对多个 k 都存在的数据集，N*(k) 不随 k 增大而增大。
- **证伪：** k = all 时，7 个数据集中至少 4 个不存在 N*。这并不意味着项目失败，而是意味着"在测试过的所有样本量上热门都更好"，作为下界报告。

## 7. 探索性假设（现在写下，并标明是探索性）

每条都带预测，这样没中也看得出来。假发现控制：Benjamini-Hochberg，q = 0.10，按族进行。

| 编号 | 假设 | 预测 |
| --- | --- | --- |
| X1 | 旧榜胜过小的新样本，直到 N 达到群体的相当比例 | 多数数据集的交叉点 N_s ≥ 群体的 30% |
| X2 | 向旧榜收缩在交叉点附近收益最大；向"平的"（与物品无关的）先验收缩什么也不改变 | 平先验的排名与原始计数完全相同（精确的对照）；收益在 N* 附近最大 |
| X3 | 误差随 N 按幂律下降并有下限；指数按头部有多重（Zipf 斜率）排序；榜首顺序类指标像阈值而不是幂律 | 11 个数据集上指数与斜率的秩相关 > 0.6 |
| X4 | Dyer-Owen 上界偏保守 | 各 N 下实际能正确排序的深度 ≥ 上界 |
| X5 | 朴素 bootstrap 排名区间在清单中段拥挤区域覆盖不足；Mogstad 等人的置信集覆盖达标但很宽 | 多数格子里，朴素方法在排名 51-200 段覆盖 < 0.93；Mogstad ≥ 0.95 |
| X6 | 活跃度有偏抽样下，小 N 时不校正的计数胜过加权（Horvitz-Thompson）计数，大 N 时反过来 | 多数数据集存在一个交叉的 N |
| X7 | 抽"最近的选择"对真相 B 更好、对真相 A 更差（符号翻转） | 多数数据集符号相反 |

| X9 | 隐私噪声主要伤害榜首；中心化 DP 在 ε ≥ 2 且 N 达到几千后几乎免费；本地 DP 需要约 100 倍的人数 | 以各数据集样本量比值的形式给出 |
| X10 | 真相 A 与真相 B 的差距（漂移）大于任何 N（群体的 40% 以内）下的抽样误差 | 多数数据集中 A-最优榜 与 B-最优榜 的差距大于抽样差距 |
| X11 | 惊喜搜索：扫描每条（数据集，N，k，估计方法，指标）曲线，找非单调形状和符号翻转；每个命中都用新种子重跑 | 以"发现 / 复现 / 未复现"的个数报告 |

## 8. 统计规则

- 格子之间比较的是"每次抽样均值"的差；区间是对抽样次数做的 cluster bootstrap（2,000 次重采样）。验证小组上的比较按同一次抽样配对。
- 跨数据集：报告效应为正的数据集个数，以及跨数据集的合并估计和区间。不用 p 值去挽救失败的假设。
- 凡是探索性的，出现的任何地方都标"探索性"并带复现状态。
- 排名中的并列随机打破；真相榜按物品编号打破并列。
- 与上述预测不符的结果，和相符的结果同样突出地报告。

## 9. 这项研究不能说明什么

- 这里的样本是从群体中随机抽的，不是真正的小群体；只有子群体阶段（X8）例外。
- 公开数据集是自愿评分或平台日志；结论是"在这些数据上看到的趋势"，不是普适规律。
- 联邦是模拟的：客户端只是用户编号上的标签，没有设备、掉线或真实的安全聚合。隐私阶段只在计数上加噪声。
- 这里的个性化模型最多只在约 1,500 个候选物品上训练（为了让机器保持安静）；这对大 N 下的热门榜有利。

## 10. 通宵运行的计算规则

只用 CPU，不用 GPU。一个调度器每 3 秒读一次芯片温度、风扇转速、内存和磁盘。这台机器的风扇空闲时约 1,400 rpm，芯片温度持续接近 80 °C 时转速才开始升高。所以当芯片超过 72 °C 或风扇超过 1,750 rpm 时，实验放慢；超过 78 °C 或 2,100 rpm 时，冻结所有工作进程。最多 4 个工作进程，工作内存 8 GB，磁盘至少剩 10 GB。每个任务都可以凭它的键重复。

## 11. 修订（2026-10-14，在一次独立代码审查之后、任何正式运行之前）

一次独立的代码审查（由同一服务商的子智能体完成，所以不算外部审计）发现了一些问题。下面逐条修复或声明。没有看到任何正式运行的结果；ml-1m 上的试跑抽样不在任何地方使用。

| 编号 | 变更 | 原因 |
| --- | --- | --- |
| A1 | **旧榜**（第 55 百分位之前的选择）是真相 A（T0 之前的选择）的一部分，约占其三分之二的行，所以"旧榜胜过样本"会有一部分是机械结果。因此 X1 和 X2 改为对照**窗口真相**（只包含第 55 百分位到 T0 之间的选择），并且样本只从这个窗口里抽（`recent_window` 组）。主网格里的 `shrunk` 估计仍然报告，但标注为"先验与真相重叠"。 | 去掉先验与真相的重叠 |
| A2 | C3 改用 **k = 10** 和 **k = all**（7 个训练模型的数据集里只有 4 个存在 k = 20，所以"7 个里至少 5 个"永远不可能达到）。预测：k = all 时至少 5/7 个数据集存在 N*，k = 10 时至少 4/7 个。证伪条件不变。 | 原规则按构造不可能满足 |
| A3 | 群体规则：早期选择至少 20 条（够 3,000 人时），否则 10 条，否则 5 条。实际上 amazon-movies-tv 和 amazon-books 用 20；另外三个较小的 Amazon 数据集用 10。 | 第 3 节的表写错了 |
| A4 | 有偏抽样（按活跃度加权、按活跃度反向加权）改用 **Poisson 抽样**：每个人独立地以已知概率入选，所以样本量是随机的（约为 N），加权计数精确无偏。 | 第一版设计在大 N 时权重有偏 |
| A5 | 验证小组打分中的并列随机打破。按时间藏起选择时，时间戳相同的选择无法区分（ml-1m 和批量导入的数据常见），这时只是部分按时间。ml-1m 的验证小组只有 194 人，所以它的数值比较嘈杂。 | 已知局限 |
| A6 | 类型子群体 = 该类型占比最高的 15% 的人；样本量 N 不超过子群体的 40%。 | 保持真实的抽样情形 |
| A7 | `ht`（加权计数）只对按活跃度的有偏抽样报告，不用于"最近的选择"。 | 在那里它不是有效的加权 |

### 第二批修订（2026-10-14，在一次设计评审之后、读到任何正式结果之前；e2 阶段已经跑了一部分，这些行保留，且没有看过）

一次设计评审发现：C1 的理由（"设计效应"）对这个估计量来说符号可能是反的；C2、C3 里有容易通过或被混杂的部分。现在定下来：

| 编号 | 变更 | 原因 |
| --- | --- | --- |
| A8 | 新增估计方法 `decay`（按时间新近程度加权的计数，半衰期 = 从第 55 百分位到 T0 的时间跨度）。探索性。 | 漂移（X10）提示最近的选择更重要 |
| A9 | **朴素计数估计的是什么。** 当 k 小于一个人的历史长度时，历史短的人贡献的行占其全部行的比例更大，所以朴素计数估计的是一份"按人归一化"的榜（真相 A_u：每个人权重 1，平均分给自己的各个选择），而不是真相 A。现在每个格子还报告 `ht`（每条保留的选择乘以 历史长度 / k，目标是真相 A）、对 A_u 的得分（`Au_*`），以及一个**有放回的组 `boot`**（各人独立抽取，不存在有限总体效应），覆盖整个 k 网格。 | C1 写下的理由可能不对；要报告机制，不只是符号 |
| A10 | **C1 判定更谨慎。** 字面检验保留（朴素计数，真相 A）。只在"最宽格子的 N 不超过群体 5%"的预算上判定（否则无放回抽样会偏袒广度）；"支持"还要求合并差值至少 0.005 NDCG@100；为正的对在 50%-75% 之间算"无定论"。对 `ht`、对 A_u、对 `boot` 组报告同样的对比。如果字面 C1 不成立而 `boot` 显示深度不比广度差，结论写成"在这里深度不比广度差，与整群抽样的直觉相反"。 | 有限总体和饱和造成的假象 |
